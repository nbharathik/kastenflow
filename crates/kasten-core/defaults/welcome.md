KastenFlow is a quiet place to write, collect and connect your notes: pages, quick
notes, a daily journal, whiteboards and PDFs. Everything is a plain Markdown
file in a folder you choose. Local history helps you recover edits; keep an
independent backup for important notes.

> [!tip] Four keys to remember
> **Ctrl+K** finds any page, text or command. **Ctrl+N** catches a quick note.
> **Ctrl+Shift+N** starts a page. **Ctrl+J** opens today's journal.

## Start here

- [ ] Type `/` on an empty line and pick a block: a heading, a to-do, a table or a toggle
- [ ] Type `[[` to link to a page, or to make a new one
- [ ] Press **Ctrl+N**, write a thought, and find it in the **Inbox**
- [ ] Open the **Journal** and write one line about today
- [ ] Make a project with **+** beside **Projects** in the sidebar
- [ ] Open **Whiteboards**, make one, and drag this page onto it

## Where things live

| Place | What it is for |
|---|---|
| **Inbox** | Quick notes, caught in a second and sorted later |
| **Journal** | One page a day, blank until you write in it |
| **Pages** | Longer writing; any page can hold sub-pages |
| **Projects** | One piece of work: its pages, cards and whiteboards together |
| **Whiteboards** | Notes and cards laid out, connected and grouped |
| **Card Library** | Every note in one place, to filter, tag and move |
| **Tag Database** | A tag as a table, board, list, gallery or calendar |
| **Calendar** | Journal days, dated notes and to-dos with a day |

## Write freely

- Markdown works as you type: `#` for a heading, `-` for a list, `[]` for a
  to-do, `>` for a quote and three backticks for code.
- Drag the handle beside any block to move it, or click it for more.
- Maths is written between dollar signs: $a^2 + b^2 = c^2$.
- On an empty page, type `/` and pick **Template…**: meetings, trips, reading notes and more.

## Organise when you are ready

- Give notes `#tags`, then give a tag properties such as a status or a date,
  and see it as a table, a board or a calendar.
- Add a day to a to-do, as in `- [ ] Book the tickets @2026-10-02`, and it
  shows in **Tasks** and on the **Calendar**.
- The right panel (**Ctrl+.**) shows a page's properties, outline, links and
  history.

## Your notes stay yours

- The files are yours: open them with any editor and keep them anywhere.
- Every change goes into the folder's history. **History** shows each one,
  and any change or page can be taken back.
- AI is optional. Chat and agents see only what you share, and API keys stay
  in your system's keychain, never in the folder.
