# Gallery

A grid of pictures, one for each note with the tag you choose. Click a picture to
open its note; arrow keys move between pictures.

## Add data

Put the picture files in this page's `assets` folder, then tag a note `#picture`
and set its `image` property to the file, for example `assets/sketch.png`. A
`caption` property adds a line under the picture. A note without an image shows a
blank frame.

To follow another tag, change `TAG` at the top of `app.js`.
