# Map

Your places on a world map: a pin with a label for each note, the countries you
name highlighted, and a list beside the map that works with the keyboard. It needs
no internet connection.

## Add data

Tag a note `#place` and give it the properties `lat` and `lon` in degrees (for
example `38.7` and `-9.1`). Optional properties:

- `country`: a country (or continent) to highlight
- `when`: a short line shown beside the place in the list

To follow another tag, change `TAG` at the top of `app.js`.
