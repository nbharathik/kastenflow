# Dashboard

A live summary of your notes: how many there are, how many are done, what is due
this week, and a table you can sort.

## Add data

Tag a note `#tracked` and give it the properties `status` (for example `todo`,
`doing`, `done`) and, if it has a deadline, `due` (a date such as `2027-03-01`).
The dashboard updates by itself.

To follow another tag, change `TAG` at the top of `app.js`.
